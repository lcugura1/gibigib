Lokalno okruženje i testiranje

Kako podići API s bazom i mail catcherom, registrirati uređaje i ručno provjeriti sigurnosne popravke.

Provjereno na Windows 11, Node 22.17, Docker 28, 2026-10-06

Preduvjeti

  • Node.js 22 ili noviji.
  • pnpm 11. Ako pnpm nije instaliran globalno, radi i corepack pnpm … (corepack dolazi s Node.js i koristi verziju iz package.json).
  • Docker Desktop (pokrenut).
Skripta pnpm typecheck u korijenu iznutra poziva pnpm. Bez globalnog pnpm-a pokreni corepack pnpm -r typecheck.

Postavljanje

corepack pnpm install
cp apps/api/.env.example apps/api/.env     # postavi POSTGRES_PASSWORD, DATABASE_URL i JWT_SECRET_KEY

cd apps/api
docker compose up -d                       # PostgreSQL + Mailpit
corepack pnpm exec prisma migrate deploy
corepack pnpm exec prisma db seed

corepack pnpm device create --kind scanner --name "Varaždin – skener (dev)"
corepack pnpm device create --kind door    --name "Varaždin – vrata (dev)"

corepack pnpm dev                          # API na http://localhost:3000
  • JWT_SECRET_KEY: openssl rand -base64 48. API se neće pokrenuti s praznom, kratkom ili "placeholder" vrijednošću.
  • Ključ uređaja ispisuje se samo jednom. Ako se izgubi: device revoke --id … pa novi device create.
  • Skener: http://localhost:3000/scanner/, pri prvom otvaranju traži ključ skenera.
  • E-mailovi (kodovi za reset lozinke): http://localhost:8025 (Mailpit).
  • Nakon promjene sheme: prisma migrate dev --name …, pa prisma generate. Prisma 7 klijent se ne generira sam.

TRUST_PROXYfalseIza reverse proxyja: broj proxyja (obično 1) ili njihove adrese/CIDR. true vjeruje svakom X-Forwarded-For i koristi se samo za lokalno testiranje.
